Imagine this, I wake up one day and tell myself, "wait, there's almost no open source software in the public domain, what if I make my own GNU-like project?" and then in the morning I wrote a code of conduct (no one contributes, only me) and a shitty manifesto that I can't read because I find it extremely cringy (I wrote it like 2 months ago wtf), anyways, I usually commit when I remember that I have an open source project only me, myself and I know.

I'll really want to get new people into the project, the problem is that, who would want to make their code completely free for everyone to copy without any form of copyright/copyleft? Probably only me and the guys from SQLite. I guess I'll be the only contributor there for years, or until I get pissed off after another error on the GitHub Workflows and just abandon it like all my projects, woohoo!

A little bit more of lore, the name "Pandix" is from "Pandora's Unix" (Pandora is the name of my cat), and I originally wanted to make an operating system, just that... I don't know anything about OSDev :(((
